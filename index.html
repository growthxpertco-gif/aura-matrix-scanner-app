Install on an Android phone

  1. Tap Download Android app.
  2. Open the downloaded file.
  3. If the phone asks, allow your browser to install apps.
  4. If Play Protect warns about an unknown app, choose to install anyway only if this link came from Growth Xpert.
  5. Tap Install, then Open.

Getting updates

The installed app tells you when a new version is ready. Tap Update now and it installs inside the app. The first time, your phone asks you to allow it. The browser version is always the latest.
